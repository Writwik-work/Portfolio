# Writwik Sati · Portfolio

Shopify & React developer portfolio. Vite + React + Tailwind.

```
npm install
npm run dev     # local dev
npm run build   # production build in dist/
```

- Projects, contact details and skills live at the top of `src/App.jsx`.
- Screenshots: `public/projects/<slug>.png` (a coloured name block shows if one is missing).
- Resume: `public/Writwik-Sati-Resume.pdf`.
- Role links for applications: `/?role=shopify` or `/?role=react`.
- Domain is set in `index.html` (canonical and Open Graph tags).
